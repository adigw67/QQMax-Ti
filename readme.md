# QQ Max（QQPro）

> ☆☆ 地表最强表 Q 改版 ☆☆

**QQ Max** 是一个面向手表的 QQ 增强改版（基于 NWear-QQ），在原版 QQ 的基础上重做了聊天、空间、联系人、资料卡等界面，补齐了大量手表端被砍掉或体验糟糕的功能，并用 Material 3 风格统一了整套界面。

改版不修改原始 APK，而是在构建时通过自研的 **ApkMixin** 工具把 Kotlin 写的功能注入到原版字节码里。开发者文档见 [docs/ApkMixin.md](docs/ApkMixin.md)。

当前版本：**M2.0**

## 功能

### 聊天

- **完全行内输入** —— 在聊天页直接用输入框承载 @、图片、回复、编辑、语音转文字，不再跳转输入法页面（默认开启）
- **行内表情按钮** —— 聊天页内嵌系统表情选择器，可设为"插入到输入框"而非直接发送
- **行内语音录制** —— 长按录音、上滑取消、转文字，无需打开独立录音页
- **记住输入草稿** —— 分会话记住未发送的文字 / @ / 图片 / 回复，跨重启持久化
- **附件浮层** —— "+" 按钮在聊天页内弹出附件菜单浮层，表情并入列表
- **滚动时保持输入栏** —— 上滑浏览历史时输入栏悬浮保留
- **材质化聊天界面** —— 输入框、回复横幅、发送 loading 全部 Material 3 化
- **长按菜单重做** —— 从零重排的 Material 长按菜单，含复制 / 部分复制 / 复制图片 / 撤回（管理员可撤回他人）/ 编辑 / 收藏等
- **合并连续同发送者消息头** —— 同一人连发时隐藏重复的头像与昵称
- **富标题栏** —— 群名 +（成员数）、其它会话未读红标、长名跑马灯
- **回到底部按钮 + 跳转锚点** —— 规则化显示、平滑滚动、远跳定位
- **逐条跳转重要消息** —— "↑X 条新消息"按钮自下而上依次跳转 @我 / 回复 / 新文件 / 新公告，到达后自动切换下一条
- **群聊 @我高亮**、**可点击 @成员 / 灰条名字**（点开资料卡）
- **聊天内搜索**（按内容 / 按发送者）
- **本地删除消息**（实时移除，无需重进会话）
- **全员禁言隐藏输入栏**

### 媒体

- **自定义图片查看器** —— 双指 / 双击缩放、点空白关闭、缩小时右滑返回
- **自定义视频播放器** —— 缩放、未下载时自动加载并播放、M3 进度条
- **相册发送流程** —— 单图 / 多图经输入栏预览统一为一条消息再发送
- **应用内拍照 / 录像**
- **系统分享双向打通** —— 长按消息系统分享外发，外部分享进来可转给好友

### 表情

- **内置经典表情 + 大表情** —— 补齐手表端缺失的经典小黄脸与动态大表情（Lottie 全屏播放）
- **商城表情选择器** —— 浏览并发送商城表情
- **商城表情动图** —— 全屏播放、保存、复制、分享

### QQ 空间

- **完全重做空间** —— 从零的 M3 动态信息流卡片、个人空间页、评论楼层、发表
- **点赞 / 评论 / 回复 / 发表 / 删除 / 举报 / @提及 / 定位**
- **媒体查看器** —— 图片 / 视频缩放查看
- **小程序卡片恢复** —— 还原手表协议里缺失的小程序分享卡片
- **通知材质化** —— 空间互动通知页 Material 化并在主页导航角标提醒

### 联系人与资料

- **联系人页材质化** —— Material 顶栏 + 搜索
- **增强资料卡** —— 重做的 Material 资料页，异步拉取扩展资料
- **好友请求 / 搜索 / 添加页材质化**
- **好友选择器搜索** —— 转发 / 分享 / 创建群 / 邀请的选择器统一加搜索框

### 群

- **群公告查看**（解码 ark 卡片，含图片）
- **群成员缓存** —— 进群即时显示成员数并支持 @ 联想

### 主页与外观

- **主页导航** —— 自定义 M3 底部导航
- **界面风格选择** —— Material 风格 / 原版风格切换
- **深色 / 浅色模式** —— 含 M3 推荐浅色配色
- **颜色选择器 & 可主题化** —— 15 个 M3 颜色 token 全部可自定义（含聊天气泡 / 文字 / 链接色），外观主题页统一管理

### 设置

- **M3 设置重做** —— 自己 / 好友 / 群设置页 Material 化，两级分类导航
- **滑块点数值直接输入**
- **缩放设置** —— 头像、圆角、字号、图片最大高度、表冠滚动速度等
- **设置导出 / 导入**（JSON / XML）

### 通知与系统

- **通知回复 + 按会话通知**
- **常驻通知标题化**（"QQ Max 正在后台运行"，无内容行）
- **反检测** —— 隐藏 root / 调试 / 模拟器 / VPN 代理等运行环境检测上报
- **自适应启动图标**

## 构建

需要 JDK 21。原版 QQ APK（待打补丁的目标）放在 `app/mixin/source.apk`（不随仓库分发）。

```bash
# 构建 release 包（输出：app/dist/QQMax_<version>.apk）
./gradlew MixinApk-release

# 构建 debug 包（更快）
./gradlew MixinApk-debug

# 用全部 CPU 核心加速
./gradlew MixinApk-release -PuseProcessorCountAsThreadCount=true
```

构建过程会编译 Kotlin 功能代码，反编译目标 APK 到 smali，打补丁后用 `app/mixin/testkey.pk8` 重新签名。
